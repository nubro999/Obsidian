
**MANify 프로토콜**은 데이터 센터를 글로벌하게 **검증 가능한 Web3 클라우드**로 업그레이드하는 것을 목표로 하는 새로운 프로토콜

**MANify.node**: 데이터 센터, 컴퓨팅, 스토리지, 감시(surveillance), 오케스트레이션 및 서비스와 관련된 기능을 담당
**MANify.consensus**: **ECCVCC** (Error Correction Code Verifiable Compute Consensus)와 **VCT** (Verifiable Coin Toss)를 포함하며, 네트워크 동기화 역할을 수행

Manify 프로토콜의 목적은 기존의 데이터센터에 데이터 검증로직을 추가한 web3 클라우드이며,
이 기능을 구현하기 위해 ECCVCC(asic 채굴 저항), VCT(채굴 합의)을 사용하여 gpu사용성을 확보함. 
즉 gpu클라우드라는 기존의 목적를 노드와 일원화 시키기위한 모든 기능을 말하는 것
