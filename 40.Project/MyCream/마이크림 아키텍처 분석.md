# 전체 배경

크랙, 캐릭터AI 등 LLM 통해서 캐릭터와 채팅하는 서비스들을 보고 영감받음

팬트리 처럼 실제 LNSF 사진 올리는 인플루언서 사진 활용하여, 인플루언서별 캐릭터를 만드는 것

기존 캐릭터챗 서비스들은 실제 사람 이미지도 아닌 AI 생성 이미지라는 한계를 극복함.

# 용어

- 플랜(구 버킷): 인플루언서가 등록한 사진 그룹. 인플루언서 마다 플랜을 여러개 생성 할 수 있고 각 플랜별 가격도 정할 수 있음.
- 캐릭터: 인플루언서 가입 시 생기는 고유 캐릭터. 인플루언서가 어떤 플랜을 사용하게 할지 지정할 수 있음.
- 스토리: 프롬프트와 플랜을 조합하여 만들어지는 캐릭터.
    - 인플루언서의 캐릭터와 기능적으로 동일하지만, ‘캐릭터’ 는 인플루언서에게 하나만 만들어지는 고유성을 지님

# 페르소나

## 인플루언서

- 사진 등록해주는 사진 제공자. UX가 극단적으로 편해야 함
- 인플루언서는 ‘플랜’ 이라는 사진 그룹 관리를 할 수 있음.
    - 플랜은 인플루언서가 지정할 수 있고, 플랜마다 월별 구독 가격 설정 가능
    - 수위별로 가격 단계를 설정하는 등으로 활용 가능
- 인플루언서는 간단한 성향 검사를 진행한다.
    - 이 과정으로 인해 인플루언서는 기본적으로 ‘캐릭터’ 라는 고유 캐릭터가 생김
- KYC 를 해야 함
- 돈 받을 계좌등록을 해야 함

## 크리에이터

- 인플루언서가 등록한 플랜을 월별 구독하여 ‘스토리’ 를 만들 수 있음.
- 마켓플레이스에서 플랜들을 탐색할 수 있음
- 일반 사용자가 플랜 내용물을 보려고 크리에이터가 될 수도 있음.
- 돈 받을 계좌등록 해줘야 함.

## 일반 사용자

- 크리에이터가 만든 ‘스토리’ 혹은 인플루언서에게 자동 생성되는 ‘캐릭터’와 채팅하는 실제 사용 유저.
- 건별로 돈을 내는 구조.

# 플로우 정리

## 인플루언서 사진 등록 → 크리에이터 생성 → 유저 사용

1. 인플루언서가 마이크림에 사진을 등록한다.
2. 인플루언서가 등록된 사진을 선택하여 플랜에 넣고 가격/이름 설정 후 저장한다.
3. 크리에이터인 유저가 마켓플레이스에서 인플루언서가 올린 플랜을 월 구독한다.
4. 크리에이터가 캐릭터를 구성하는 프롬프트를 작성하고 구독한 플랜을 붙여 ‘스토리’ 를 배포한다.
5. 유저가 돈을 사용하여 크리에이터들이 올린 스토리들을 탐색하고 실제 채팅을 한다.
6. 유저가 낸 돈은 마이크림/인플루언서/크리에이터 가 분배하여 가진다.

## 인플루언서 사진 등록 → 유저 사용

1. 인플루언서가 마이크림에 사진을 등록한다.
2. 인플루언서가 등록된 사진을 선택하여 플랜에 넣고 가격/이름 설정 후 저장한다.
3. 인플루언서가 성향 검사를 하고 ‘캐릭터’ 가 자동으로 생성된다.
4. 유저가 돈을 사용하여 자동 생성된 캐릭터들을 탐색하고 실제 채팅을 한다.
5. 유저가 낸 돈은 마이크림/인플루언서 가 분배하여 가진다.

인플루언서는 팬트리와 연동해서 주기적으로 올라가는 사진이 업데이트 되는건가요?

크리에이터가 아닌 유저는 플랜사진을 볼 수 없고, 대화를 통해서만 사진을 볼 수 있는 건가요? > 사진이 올라가는 조건이나 주기가 정해져 있나요?

스토리에서 스토리 라인 (기승전결)이 존재하나요?

현재 플랜, 스토리, 마켓플레이스
